# 月白（つきしろ）

俳句と、そのときの景色を残すための句帳アプリです。日本語・縦書きの句カードと、スマートフォンに対応した入力画面を備えています。

## 使い方

`index.html` をダウンロードしてブラウザーで開くだけで利用できます。インストールやアカウント登録は不要です。

1. 「一句を詠む」欄に俳句を入力します。スマートフォンでは「＋ 一句を詠む」を押すと入力欄が開きます。
2. 季語・季節・詠んだ日・メモを添えて「句帳に残す」を押します。
3. 句カードの「編集する」で推敲し、星印でお気に入りにできます。
4. 句・季語・メモの検索、季節、お気に入りで絞り込めます。
5. 「バックアップ」でJSONファイルを保存し、「復元」で取り込めます。復元は句帳全体を置き換えるため、実行前に確認画面を表示します。

五七五の音数チェックは行いません。自由律・字余り・字足らずも記録できます。

## 保存先について

- データはブラウザーの `localStorage` に保存します。サーバーやGitHubに俳句を送信しません。
- 別のブラウザー・端末・URLには自動同期されません。バックアップと復元で移行してください。
- ブラウザーのデータ消去やプライベートモードの終了で消える場合があります。定期的にバックアップしてください。
- ファイルを直接開いた場合の保存方法はブラウザー依存です。同じ場所のファイルを同じブラウザーで開いてください。安定して使う場合は静的ホスティングを利用してください。
- 外部ライブラリー・外部フォント・通信APIは使用していません。

## GitHub Pagesで利用する場合

リポジトリの **Settings → Pages → Build and deployment** で、**Deploy from a branch**、**main**、**/(root)** を選択して保存してください。

設定後のURLは `https://metaanthr34.github.io/tsukishiro/` です。Pagesが有効になり、配信が完了してから利用できます。ローカル版の句はバックアップ・復元で移してください。

## 構成

- `index.html`: HTML・CSS・JavaScriptをまとめた単一ファイルのアプリ
- `README.md`: 利用方法

俳句は最大200文字、季語50文字、メモ2,000文字、句帳は10,000句まで対応します。実際の保存上限はブラウザーの空き容量にも依存します。保存に失敗した場合、入力内容を残してエラーを表示します。
